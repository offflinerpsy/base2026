Know what each check can tell you.

Local file tools process only what you supply. HTML SEO Checker sends public HTML to the Base2026 checker. Research tools use the public evidence API. None of these tools edits your site or guarantees indexing or rankings.

Keep private client information and credentials out of server checks and public research requests. The Sitemap Builder and local file checks keep their inputs in your browser.
