How the check works

Keep the source path attached.

  1. ID

    Start with public IDs

    Search the admitted public corpus first. This tool accepts canonical tiktok-video-... record IDs and tiktok:creator:video_id source IDs, not uploads, credentials or arbitrary URLs.

  2. GROUP

    Compare observable metadata

    Records, attributed creators and normalized original URLs are grouped independently. Missing attribution, missing URLs and unavailable records are not silently dropped.

  3. LINK

    Inspect before deciding

    Open each Base2026 record and original source. Repeated metadata can guide the next check, but it does not establish consensus, truth, quality or independence.

What it is

A small provenance utility.

  • A bounded read-only lookup over public Base2026 source records.
  • A deterministic comparison of exact IDs, creator attribution and original-source URLs.
  • A Markdown/JSON card that keeps links and unknowns together.

What it is not

A consensus or truth checker.

  • Not a fact-check, ranking, quality or independence score.
  • Not an external crawl, rank, backlink or Search Console measurement.
  • Not an LLM verdict, login, storage, private-data, raw-transcript or media workflow.

FAQ

Boundaries before conclusions

What counts as one selected record?

One unique canonical public Base2026 record ID counts once, even if the same ID is pasted repeatedly. The check never invents IDs from a title or source URL.

Why are creator and original-source counts separate?

A creator may have multiple records, and a record may have missing or unresolved attribution. A normalized original URL is another relationship field; neither count is a substitute for the exact record list.

Does a repeated creator or URL prove the records are dependent?

No. It only reports a relationship visible in the selected public metadata. Read the records and originals, then decide what additional evidence is needed.

What happens when metadata is missing?

The record remains in the selected set with an unresolved creator or original-source state. Missing metadata is included in the export instead of being treated as a match or silently removed.

Does the tool save my IDs or export?

No. The route uses the existing read-only public record endpoint and creates the export in your browser. It does not require an account or submit a write request.
