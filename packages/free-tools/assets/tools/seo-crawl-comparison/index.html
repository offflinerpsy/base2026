Free SEO crawl comparison

Compare the observations before and after a site change. Keep field changes separate from missing coverage and planned changes.

Local processing · no signup · up to 5,000 records per input, 2 MiB per file, 4 MiB combined. Robots.txt is limited to 64 KiB.

Add your data

Required: url. Compare any shared columns: status,title,canonical,robots,h1,description,link_count. Standard header aliases are supported.

Use the same columns and crawler scope where possible. Up to 5,000 rows per file. Exact URL joins; no automatic mapping between different URLs.

      What this checks

      • Reports supplied snapshot changes, not live page behavior, a ranking effect or the cause of a traffic change.
      • A URL found in one partial export is an observation about coverage, not proof that the page was added or deleted.
      • Only shared supported fields are compared. Missing columns stay unknown. Invalid or conflicting duplicate rows are excluded from comparison.

      Inputs and results stay in tab memory until cleared, page navigation or closing. No uploads, target requests, storage, analytics or AI calls are used.
