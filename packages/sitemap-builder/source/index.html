From your URL list to a file you can review.

      
  1. Import the URLs you intend to include. Use a UTF-8 TXT or CSV file. Add one existing XML urlset if you want a comparison.
  2. Choose one host and review the result. Check the added, missing, excluded and duplicate records. URL paths, queries, letter case and trailing slashes are preserved.
  3. Download the files you need. Get the sitemap XML, changes CSV, input manifest or readable report. Review the sitemap before adding it to your own site. Upload the reviewed XML to a public location on the selected host, commonly /sitemap.xml, then use its URL in your site’s sitemap configuration or search-engine submission tool. This app does not publish or submit it.

      
Will this crawl my website or check Google indexing?
No. It processes the files you choose in your browser. It does not visit the URLs, validate HTTP status, choose canonical URLs or submit anything to a search engine. A valid sitemap does not guarantee indexing.

      
Which sitemap files can I compare?
One XML urlset, with up to 5,000 URL records and 2 MiB per file. Sitemap indexes, XML extensions, DOCTYPE and entity declarations are unsupported. A lastmod value is copied only from a matching supplied URL with valid date syntax; it is never guessed.

      
Where do my files go?
The app processes them in this tab. Inputs and results remain in tab memory until you clear them or close the tab. Downloads are files you choose to keep. The app makes no uploads, target URL requests, analytics calls or AI calls.
