# Base2026 Sitemap Builder

A self-contained browser utility. See [source/README.md](source/README.md) for input contracts, source links, privacy, limits and licenses. Serve `source/` over HTTP to use the interface.

From this package directory:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory source
```

Open `http://127.0.0.1:8000/`. Repository source: [packages/sitemap-builder](https://github.com/offflinerpsy/base2026/tree/main/packages/sitemap-builder).

## Reproduce the parser checks

Run from this package directory. The accepted original tests used Node.js **22.19.0**. The independent XML/CSV oracles use Python 3's standard library (ElementTree/Expat, csv and hashlib); each oracle records its actual Python and Expat runtime where applicable. No npm install, credentials, model or production service is needed.

Run in this order because later commands read evidence generated by earlier ones:

```sh
node tests.mjs
node regressions.mjs
python3 oracle.py
node worker-probe.mjs
node r3-regressions.mjs
python3 r3-oracle.py
node r3-worker-probe.mjs
```

The scripts use the unchanged `source/core.mjs` and `source/worker.mjs`. They create synthetic fixtures, maximum-size examples and local `*-EVIDENCE.json` reports in this package directory. Test inputs are made-up URLs; they are not users or demand observations. Existing reports are not required: the command order regenerates what the subsequent checks need. No operational receipts, real user inputs or deployment configuration are included.

For the interface, serve `source/` over HTTP and test import, explicit host selection, build, reset and all four downloads in a real browser. A successful parser test does not establish browser behavior, deployment, indexing or user value.
